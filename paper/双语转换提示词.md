# 英文文献 → 中英对照 PDF：可复用提示词

> 适用于任何有 shell、能装 Python 包、能跑无头浏览器的 agent harness（Qoder / Claude Code / Codex / Cursor 等）。
> 翻译质量取决于模型本身；**流程与校验**照下面这份提示词走，就能复现同样的成品完整度。

---

## 一、精简版（一段话，直接粘贴）

> 把 `xxx.pdf` 做成中英对照 PDF：保持原文行文顺序（题名/摘要/各章节/图表位置/参考文献），
> 每个正文块先英文原文、紧跟中文译文；图、表、公式**整块从原 PDF 裁剪成高清图片**原样保留，
> 只在图下补一行中文图注。用 PyMuPDF 抽文本块与矢量/位图包围盒、用无头 Chrome 打印成 PDF，
> 脚本要落进仓库可重跑。**交付前必须做三件事**：①用原文逐句回查覆盖率，列出缺失并逐条判定是"真丢了"
> 还是"在图里/是水印"；②中英按英文前缀强制配对，缺译文就报错退出；③把 3–5 页渲染成图片肉眼检查图注、
> 表线、公式是否完整。术语首现给中英对照，引用编号 [12] 与数字单位照抄，人名邮箱与参考文献不译。

---

## 二、完整版（长论文 / 想一次做对就用这份）

```
任务：把 <PDF 路径> 转成中英对照 PDF，输出 <目录>/paper_bilingual.pdf。

【技术路线，不要另起炉灶】
1. 抽取（Python + PyMuPDF，脚本存进仓库，可重跑）：
   - 按页取 text blocks；双栏排版的阅读顺序：整宽块单独成段并打断栏流，
     其余按"先左栏全部、再右栏全部"输出。
   - 图/表识别：行首匹配 (Figure|Table)\s+\d+\. 的块为图注；图注可能与子图标号
     （如 "(j) Ground Truth"）同处一块，要按行切分定位；正文里 "as shown in
     Table 6. With ..." 这类句中匹配必须排除（判据：图注之前的文本长度 > 30 字符）。
   - 图区裁剪框：从图注出发**迭代生长**，反复吸收 ①get_drawings()/get_image_info()
     得到的矢量/位图包围盒 ②邻近的"非散文"文本块（子图标号、表格单元格），
     直到不再变化。散文判据：块宽 < 300pt 且长度 > 120 字符，且含句间边界
     [a-z]\.\s+[A-Z]，或词数 > 18 且数字密度 < 8%。
   - 公式：PDF 会把 "\label" 抽成 "\ l a b e l"，所以匹配 LaTeX 前先去掉所有空格；
     纯符号块（{ } ^ _ & = 数字）也算公式碎片；碎片按邻近度聚类成一个裁剪框，
     并**迭代合并**（合并后包围盒变大才能继续吸收邻居）。
   - 连字符跨行：先统计全文词表（必须排除只在断行处出现的左/右碎片），
     再判定：两半拼起来是词表里的真词 → 粘连（net-work→network）；
     否则保留连字符（resource-constrained）。把全部决策打印出来人工复核，
     漏网的特例用显式白/黑名单钉住。
   - 段落缝合：被图表截断的段落（前段无句末标点、后段以小写开头）要并回一段，
     **循环执行**，因为一段可能被截断多次；图表移到该段之后。
2. 译文（模型自己写，不调外部翻译 API）：
   - 逐段对应，不合并、不拆散、不省略；引用编号 [12]、数字、单位、模型名、
     公式变量原样保留；术语首次出现给"中文（English）"。
   - 图注/表注单独成表翻译；人名、邮箱、参考文献条目不译。
3. 排版：生成 HTML（@page A4 + 边距），英文段落在前、中文段落在后并用颜色/左边框区分；
   图表公式用第 1 步的裁剪图；再用无头 Chrome --print-to-pdf 出 PDF。

【强制校验，三项都要做，缺一不可】
A. 覆盖率回查：把 PDF 原文按句切分，逐句取前 70 字符（去空格、去连字符）在抽取结果里查找；
   打印所有"查不到"的句子，并逐条归类为：真丢了（必须修）/ 在图表裁剪图内（正常）/
   公式（正常）/ arXiv 水印与页码（正常）。
B. 中英配对：按英文前缀配对，任何"有英文无译文"或"有译文没被用上"都让脚本报错退出。
C. 数量核对：裁剪图数量 == 论文里 Figure 数 + Table 数 + 公式数；
   把成品 PDF 的 3–5 页渲染成 PNG 用肉眼检查图注、表格线、公式是否完整清晰。

【交付】
说明页数、图表与公式数量、正文覆盖率结论；把脚本与译文文件路径列出；
说明为适配本文档版式做过的判据，便于换论文时复用或调整。
```

## 三、换论文时要调的参数

| 情况 | 改哪里 |
|---|---|
| 单栏 PDF（多数期刊/arXiv preprint） | 关掉分栏逻辑，整页按 y 排序即可 |
| IEEE 双栏、页眉有 running head | 调整"跳过页眉/页码"的 y 阈值与正则 |
| **扫描版 / 图片型 PDF**（没有文本层） | 本流程失效：先 OCR（PaddleOCR / MinerU / Azure DI）再做版面分析，或直接把整页裁图 + 逐段 OCR 文本翻译 |
| 公式是 MathML/嵌入字体 | 抽查裁剪图；必要时改用 LaTeX 源码（论文有 arXiv 源时优先） |
| 只要正文不要参考文献 | 参考文献段落整体跳过，并在开头注明 |
| 图表太多、想控制页数 | 裁剪倍率从 3x 降到 2x；或只裁表不裁图 |

## 四、为什么必须带"校验"这一段

抽取类任务最容易出的事故是**静默丢内容**：某段正文被当成表格单元格吞进裁剪图、或图注判据太宽把整段吞掉。
只看成品 PDF 的前几页发现不了——它会表现成"某句话突然不见了"。
把覆盖率回查、配对断言、数量核对写成硬性步骤，模型就没法"看起来做完了"。
