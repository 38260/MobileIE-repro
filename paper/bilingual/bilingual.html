Abstract

摘要

Recent advancements in deep neural networks have driven significant progress in image enhancement (IE). However, deploying deep learning models on resource-constrained platforms, such as mobile devices, remains challenging due to high computation and memory demands. To address these challenges and facilitate real-time IE on mobile, we introduce an extremely lightweight Convolutional Neural Network (CNN) framework with around 4K parameters. Our approach integrates reparameterization with an Incremental Weight Optimization strategy to ensure efficiency. Additionally, we enhance performance with a Feature Self-Transform module and a Hierarchical Dual-Path Attention mechanism, optimized with a Local Variance-Weighted loss. With this efficient framework, we are the first to achieve real-time IE inference at up to 1,100 frames per second (FPS) while delivering competitive image quality, achieving the best trade-off between speed and performance across multiple IE tasks. The code will be available at https: //github.com/AVC2-UESTC/MobileIE.git.

深度神经网络的最新进展推动了图像增强（IE）的大幅提升。然而，由于计算与显存开销巨大，把深度学习模型部署到移动设备这类资源受限的平台上仍然困难。为应对这一挑战并让移动端实时图像增强成为可能，我们提出了一个参数量仅约 4K 的极轻量卷积神经网络（CNN）框架。我们的方法把结构重参数化与增量权重优化（IWO）策略结合起来以保证效率；同时用特征自变换（FST）模块与分层双路注意力（HDPA）机制提升性能，并用局部方差加权（LVW）损失进行优化。借助这一高效框架，我们首次在保证有竞争力画质的同时实现高达 1,100 FPS 的实时图像增强推理，并在多个图像增强任务上取得速度与性能之间的最佳折中。代码将发布于 https://github.com/AVC2-UESTC/MobileIE.git。

1. Introduction

1. 引言

Image enhancement (IE) aims to restore images degraded by factors such as camera limitations [86], poor lighting [48], or challenging environments (e.g., underwater [55]). With the growing prevalence of smart devices and embedded systems, real-time image enhancement has become essential in applications like mobile devices. These scenarios require not only high-quality output but also real-time processing, demanding efficient image enhancement within the constraints of limited computational resources [9, 16–18]. Recent advancements in Transformer-based [14, 42, 69] and Diffusion-based [79, 84, 96] methods have demonstrated significant progress in image enhancement (IE) tasks. However, their reliance on computationally expensive self-attention mechanisms and iterative diffusion processes makes them unsuitable for mobile devices. While lightweight models have been developed to reduce computational complexity using parameter compression and low-FLOPs architecture designs [57, 59, 63, 80, 83], these approaches often compromise enhancement quality, making it challenging to achieve high performance across a wide range of degradation scenarios [1]. Furthermore, the increasing demand for high-resolution images [69] exacerbates the computational burdens on mobile platforms. Besides facing computational bottlenecks, current IE methods are typically optimized for specific degradation types, restricting their adaptability. Although advanced operators [10, 11] have shown effectiveness in certain tasks, their complexity makes them unsuitable for mobile deployment. Consequently, designing a universal and efficient network capable of real-time IE on resource-constrained devices remains a significant research challenge. We believe that mobile-based IE should strike a balance between speed and performance, leveraging general architectures and hardware-friendly operators [66, 88]. To address these challenges, we introduce MobileIE, an efficient method designed for real-time enhancement in resource-constrained environments, optimizing both performance and resource utilization. Although degradation types vary widely, IE tasks share common requirements: global information for structural integrity and local details for accurate recovery. This commonality enables the use of universal modules across different tasks. Building on this concept, MobileIE employs a streamlined topology and deployable operators to achieve efficient performance on resource-constrained devices. We decouple the training and inference phases, simplifying the feedforward structure for more efficient inference. At the core of our design is MBRConv, a Multi-Branch Re-parameterized Convolution, which captures multi-scale features using various convolution sizes. These features are then processed through concatenation, compression, and mapping to achieve the desired output dimensions. Additionally, we introduce a Feature Self-Transform (FST) module, which enhances the feature representation capability of linear convolutions by capturing nonlinear relationships through secondary feature interactions. To enhance focus on critical regions, we simplify the attention mechanism and develop a hardware-friendly Hierarchical Dual-Path Attention (HDPA) mechanism, which efficiently fuses global and local features. To overcome training bottlenecks, we introduce an Incremental Weight Optimization (IWO) Strategy and a Local Variance Weighted (LVW) Loss function. The IWO strategy freezes prior knowledge, integrates it into trainable convolutional kernels, and re-parameterizes these into new kernels to boost model performance. Meanwhile, the LVW Loss function enhances accuracy without increasing the number of parameters. Key contributions of this paper include: • We introduce MobileIE, a framework designed for real-time image enhancement on mobile devices, featuring compact and efficient modules tailored for resource-constrained environments. • We propose an Incremental Weight Optimization (IWO) Strategy and a Local Variance Weighted (LVW) Loss to address the challenges of training compact models, enhancing performance without adding complexity. • We demonstrate that MobileIE achieves state-of-the-art speed and performance across three image enhancement tasks, sustaining over 100 FPS and enabling seamless deployment on mobile devices.

图像增强（IE）的目标是恢复因相机器件局限 [86]、光照不足 [48] 或恶劣环境（例如水下 [55]）而退化的图像。随着智能设备与嵌入式系统日益普及，实时图像增强在移动端等应用中变得不可或缺。这类场景既要求高质量输出，又要求实时处理，因此必须在有限算力约束下完成高效的图像增强 [9, 16–18]。基于 Transformer [14, 42, 69] 与基于扩散模型 [79, 84, 96] 的方法近年在图像增强任务上取得了显著进展，但它们依赖计算代价高昂的自注意力机制和迭代式扩散过程，不适合移动设备。虽然已有工作通过参数压缩与低 FLOPs 架构设计来降低计算复杂度、得到轻量模型 [57, 59, 63, 80, 83]，但这些做法往往牺牲增强质量，难以在种类繁多的退化场景下都保持高性能 [1]。此外，对高分辨率图像日益增长的需求 [69] 进一步加重了移动平台的计算负担。除了算力瓶颈，现有 IE 方法通常只针对特定退化类型优化，泛化能力受限；尽管一些先进算子 [10, 11] 在特定任务上有效，其复杂度使它们难以在移动端部署。因此，设计一个能在资源受限设备上做实时图像增强的通用高效网络，仍然是一个重要的研究挑战。我们认为，面向移动端的图像增强应当在速度与性能之间取得平衡，依靠通用架构与硬件友好算子来实现 [66, 88]。为应对上述挑战，我们提出 MobileIE——一种为资源受限环境下的实时增强设计、同时优化性能与资源占用的方法。尽管退化类型差异很大，各类 IE 任务有着共同的需求：维持结构完整性所需的全局信息，以及精确恢复所需的局部细节。

这种共性使得不同任务可以复用同一套通用模块。基于这一思路，MobileIE 采用精简的拓扑结构与可部署的算子，在资源受限设备上实现高效的性能。我们把训练阶段与推理阶段解耦，简化前向结构以获得更高效的推理。设计核心是 MBRConv——一种多分支重参数化卷积，用不同卷积核尺寸捕获多尺度特征，再经拼接、压缩与映射得到所需的输出维度。此外我们提出特征自变换（FST）模块，通过二阶特征交互捕获非线性关系，从而增强线性卷积的特征表达能力。为了让模型更关注关键区域，我们简化了注意力机制，提出硬件友好的分层双路注意力（HDPA）机制，高效融合全局与局部特征。为克服训练瓶颈，我们提出增量权重优化（IWO）策略与局部方差加权（LVW）损失：IWO 冻结先验知识、将其融入可训练的卷积核并重新参数化为新核以提升性能，LVW 则在不增加参数的前提下提升精度。本文的主要贡献包括：• 我们提出 MobileIE，一个面向移动端实时图像增强的框架，其紧凑高效的模块专为资源受限环境设计。• 我们提出增量权重优化（IWO）策略与局部方差加权（LVW）损失，用于解决紧凑模型训练困难的问题，在不增加复杂度的前提下提升性能。• 我们证明 MobileIE 在三项图像增强任务上同时取得最先进的速度与性能，可持续超过 100 FPS，并能在移动设备上无缝部署。

2. Related Works

2. 相关工作

2.1. Low-Level Vision Tasks

2.1. 底层视觉任务

This section covers three key tasks: Low-Light Enhancement (LLE), Underwater Image Enhancement (UIE), and end-to-end Image Signal Processing (ISP). LLE. LLE focuses on mitigating color distortion and noise in degraded images. Retinex-based [5, 46, 78, 81, 85] enhance images by separating illumination and reflectance. Zero-DCE [28] adjusts underexposed images using a luminance enhancement curve, and PairLIE [26] learns enhancement from varying lighting conditions. Transformerbased [5, 71, 76] and Mamba-based [93] methods have also achieved notable success, while Diffusion-based [39, 85] methods excel at generating accurate images in extremely low-light conditions, even with noise and limited data. UIE. Compared to traditional UIE methods [24, 101], CNN-based [38, 52, 53, 61] directly learn feature representations from underwater images. Five A+ [40] proposed a two-stage framework with a pixel attention module for real-time enhancement. Transformer-based [41, 55] and Mamba-based [2, 12] models more effectively handle complex underwater scenes with their global receptive fields. Additionally, Diffusion-based [65, 96] approaches reduce noise and enhance contrast efficiently. ISP. Learning-based ISP pipelines replace traditional multi-module systems by employing end-to-end models that directly process RAW input into RGB images. PyNet [35] focuses on mobile ISPs, while MW-ISP [34] and AWNet [20] improve performance using wavelet transforms. LiteISP [95] resolves misalignment between RAW and sRGB images, achieving better results through joint learning. Rawformer [56] eliminates the need for paired datasets with an unsupervised Transformer, and DiffRAW [84] introduces diffusion models into ISP. Several ISP challenge works [34, 36, 37] have also produced notable results.

本节涵盖三个关键任务：低光增强（LLE）、水下图像增强（UIE）与端到端图像信号处理（ISP）。低光增强。LLE 关注抑制退化图像中的色彩失真与噪声。基于 Retinex 的方法 [5, 46, 78, 81, 85] 通过分离光照与反射分量来增强图像；Zero-DCE [28] 用亮度增强曲线调整曝光不足的图片，PairLIE [26] 从不同光照条件下学习增强。基于 Transformer 的方法 [5, 71, 76] 与基于 Mamba 的方法 [93] 也取得了可观成效；基于扩散模型的方法 [39, 85] 在极暗、含噪且数据有限的条件下仍能生成准确图像。水下图像增强。与传统 UIE 方法 [24, 101] 相比，基于 CNN 的方法 [38, 52, 53, 61] 直接从水下图像学习特征表示。Five A+ [40] 提出带像素注意力模块的两阶段框架以实现实时增强；基于 Transformer [41, 55] 与基于 Mamba [2, 12] 的模型凭借全局感受野更好地处理复杂水下场景；基于扩散模型的方法 [65, 96] 则高效地降噪并增强对比度。图像信号处理。基于学习的 ISP 流程用端到端模型直接把 RAW 输入映射为 RGB 图像，取代传统的多模块流水线。PyNet [35] 聚焦移动端 ISP，MW-ISP [34] 与 AWNet [20] 借助小波变换提升性能；LiteISP [95] 解决 RAW 与 sRGB 之间的错位问题，通过联合学习取得更好结果；Rawformer [56] 用无监督 Transformer 摆脱对成对数据的依赖，DiffRAW [84] 把扩散模型引入 ISP。此外若干 ISP 挑战赛工作 [34, 36, 37] 也取得了可观成果。

2.2. Efficient Architectures Design

2.2. 高效架构设计

Efficient neural networks aim to balance computational complexity and performance. Models like MobileNet [32] and ShuffleNet [91] achieve high performance with fewer FLOPs, while GhostNet [29] and FasterNet [8] generate feature maps through cost-effective operations. StarNet [51] excels in extracting rich representations with star-shaped operations, and VanillaNet [7] demonstrates minimalism’s power using only a few convolutions. Furthermore, re-parameterization strategies have also proven successful in efficient network design. Models like ACNet [21], DBB [22], and RepVGG [23] use multi-branch topologies to accelerate inference, while RepGhost [23], RepViT [68], and MobileOne [66] adopt similar approaches to enhance performance. Several NTIRE challenge submissions [15, 45, 60] have utilized re-parameterized structures to accelerate inference in efficient IE tasks.

高效神经网络旨在平衡计算复杂度与性能。MobileNet [32]、ShuffleNet [91] 等模型以更少的 FLOPs 取得高性能，GhostNet [29] 与 FasterNet [8] 用低成本运算生成特征图；StarNet [51] 借助星形运算出色地提取丰富表示，VanillaNet [7] 则说明只用少量卷积也能发挥极简主义的力量。此外，重参数化策略在高效网络设计中同样成功：ACNet [21]、DBB [22]、RepVGG [23] 等模型用多分支拓扑加速推理，RepGhost [23]、RepViT [68]、MobileOne [66] 采用类似思路提升性能。多件 NTIRE 挑战赛参赛工作 [15, 45, 60] 也利用重参数化结构来加速高效图像增强任务的推理。

3. Proposed Method

3. 本文方法

3.1. Overall Pipeline

3.1. 整体流程

We aim to design an efficient IE model that balances parameters, speed, and performance. Following the simplicity principle [88], we adopted a streamlined topology based on basic operations, illustrated in Figure 2. The proposed MobileIE, built on Re-parameterization, integrates four key components: shallow feature extraction, deep feature extraction, feature transform, and an attention mechanism. During training, the degraded image first passes through MBRConv5 × 5 and the PReLU activation function to extract shallow features. Two MBRConv3 × 3 and FST modules then process these to learn deeper features. The HDPA mechanism directs the model’s focus to important regions, and MBRConv3 × 3 refines the output. To address training performance bottlenecks, we introduce the IWO strategy and LVW loss function. In inference, all MBRConv layers are re-parameterized into standard convolutions, reducing parameters while maintaining performance. MobileIE’s streamlined structure ensures fast inference and easy deployment on mobile devices. Despite its simplicity, MobileIE surpasses SOTA lightweight IE models, as shown in Figure 1.

3.3. Feature Self-Transform

3.3. 特征自变换

While MBRConv captures multi-scale features, its linear operations restrict higher-order feature interactions. To address this, we introduce FST, which employs a quadratic interaction mechanism [51] to boost the model’s nonlinear expressiveness. In FST, the input features are element-wise multiplied by themselves, scaled by a learnable parameter, Scale, and adjusted by a learnable bias term.

MBRConv 虽能捕获多尺度特征，但其线性运算限制了高阶特征交互。为此我们提出 FST：它采用二阶交互机制 [51] 来增强模型的非线性表达能力。在 FST 中，输入特征与自身逐元素相乘，再乘以可学习参数 Scale，并加上一个可学习偏置项进行调整。

This quadratic interaction captures more complex relationships between features, unlike traditional linear combinations. A learnable bias term is also applied channel-wise to fine-tune the output further. FST significantly improves feature representation by capturing higher-order interactions, while the learnable bias enhances adaptability across dimensions. This design balances improved expressiveness with computational efficiency, making FST suitable for lightweight models and real-time inference.

与传统的线性组合不同，这种二次交互能捕获特征之间更复杂的关系；同时按通道施加可学习偏置项，对输出进一步微调。FST 通过捕获高阶交互显著提升特征表示能力，可学习偏置则增强了跨维度的适应性。这一设计在提升表达能力的同时兼顾了计算效率，使 FST 适合轻量模型与实时推理。

4.1. Experimental Settings

4.1. 实验设置

Implementation Details. We implemented MobileIE in PyTorch. The model uses the Adam optimizer with a cosine annealing learning rate schedule, starting at 0.001. The learning rate is reset every 50 epochs with gradual decay. A 10-epoch warm-up phase [30] is applied with a fixed learning rate of 1e-6. The model is trained for 2,000 epochs, incorporating an Incremental Weight Optimization Strategy for improved convergence. For the ISP task, input data is preprocessed into a 256 × 256 Bayer pattern. Dataset and Metrics. For LLE task, the LOLv1 [75] and LOLv2 [82] datasets are used for both training and testing. For UIE and ISP tasks, the UIEB [43] and ZRR [35] datasets are utilized, respectively.

5. Conclusion

5. 结论

In this paper, we introduce MobileIE, a lightweight CNN with only 4K parameters designed for real-time image enhancement on mobile devices. MobileIE combines simplicity with high performance across low-light image enhancement, underwater image enhancement, and image signal processing tasks. Key components such as the MBRConv, Feature Self-Transform module, Hierarchical Dual-Path Attention mechanism, and Local Variance-Weighted loss enable MobileIE to achieve superior results while maintaining an inference time of around 0.9 ms. Furthermore, MobileIE can be easily deployed on any commercial mobile device with minimal computational overhead and efficient resource utilization. Future work will explore optimizations to expand MobileIE’s application to more different tasks.

本文提出 MobileIE——一个只需 4K 参数、面向移动设备实时图像增强的轻量 CNN。在低光增强、水下增强与图像信号处理三类任务上，MobileIE 同时做到了结构简单与性能出色。MBRConv、特征自变换模块、分层双路注意力机制与局部方差加权损失等关键组件，使 MobileIE 在保持约 0.9 ms 推理耗时的同时取得更优结果。此外，MobileIE 可以方便地部署在任何商用移动设备上，计算开销极小、资源利用高效。未来工作将探索更多优化，把 MobileIE 的应用扩展到更多样的任务。
